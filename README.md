# Gemini Chat PWA

Gemini API を直接呼び出す、個人用のチャット PWA です。
Android の Gemini アプリ風の UI で、サーバー不要・ビルド不要。静的ファイルを置くだけで動きます。

- API キーとチャット履歴は **ブラウザの localStorage** に保存（ブラウザごとに独立）
- 長い会話でもトークンを節約できる **送信モード切り替え**（全文 / 要約＋直近N話）
- 小説のように 1 話 1 万文字クラスの長文を何話も続ける使い方を想定

## 機能

| 区分 | 内容 |
| --- | --- |
| UI | Gemini 風のチャット画面、左上のハンバーガーメニューから履歴と設定、下部に入力欄。ライト / ダーク対応。画面幅 900px 以上では履歴を左に常時表示し、チャット領域を広く使う |
| 応答 | ストリーミング表示、送信中は停止ボタン、Markdown（太字・インラインコード・コードブロック）表示 |
| 履歴 | 保存・再開、履歴ごとに **名前の変更**・**エクスポート（Markdown / JSON）**・**削除** |
| バックアップ | 全履歴を JSON で書き出し / 読み込み（API キーは含まれません） |
| 送信モード | チャットごとに「全文」「要約＋直近N話」を切り替え。送信見込みトークン数と削減率を表示 |
| 設定メモ | チャットごとの system instruction（世界観・文体など）。毎回送信されます |
| 自動要約 | 800 文字を超える返信は、別モデルで 300 字ほどのあらすじを自動生成して保存 |
| 失敗時 | 返信が始まる前の 429 / 500 / 503 / 504 は 2・5・10 秒間隔で最大 3 回自動リトライ。失敗時は「再試行」ボタン |
| コピー | 自分の送信メッセージ・Gemini の返信ともにコピー可能 |
| PWA | ホーム画面に追加してアプリのように起動。アプリ本体はオフラインでも開けます（チャット送信にはネット接続が必要） |

## セットアップ

### 1. API キーを用意する

[Google AI Studio](https://aistudio.google.com/) で API キーを発行します。

### 2. 配置する

このフォルダの中身をそのまま静的ホスティングに置きます。Service Worker を使うため、**HTTPS または localhost** が必要です。

**GitHub Pages**

1. 新しいリポジトリを作り、ファイル一式をルートに置いて push
2. Settings → Pages → Source を「Deploy from a branch」、ブランチ `main`、フォルダ `/ (root)` にする
3. 発行された URL（`https://<user>.github.io/<repo>/`）を開く

**ローカルで試す**

```bash
cd gemini-chat-pwa
python -m http.server 8000
# http://127.0.0.1:8000 を開く
```

Cloudflare Pages / Netlify など、他の静的ホスティングでも動きます。パスはすべて相対指定です。

### 3. 初期設定

1. 左上のメニュー → 設定 を開く
2. API キーを入力して保存
3. スマホではブラウザのメニューから「ホーム画面に追加」

## 使い方

- **送信**: 送信ボタン、または `Ctrl + Enter`（`Enter` は改行）
- **新しいチャット**: 右上の鉛筆アイコン
- **履歴の操作**: メニュー内の履歴の右にある「⋮」から、名前の変更・エクスポート（Markdown / JSON）・削除
- **送信モードの切り替え**: 画面上部の「📤」バーをタップ

### 送信モードについて

Gemini API は会話を覚えていないため、**毎回過去のやり取りをまとめて送る**必要があります。長編を続けると送信量が話数に比例して増えるため、次のモードを用意しています。

| モード | 送る内容 |
| --- | --- |
| 全文 | 過去のやり取りをすべて全文で送る |
| 要約＋直近N話 | 古い返信は自動生成した要約に置き換え、直近 N 話（1〜5）だけ全文で送る |

- 要約があるのは 800 文字を超える返信だけです。要約がない返信は全文で送られます。
- 要約は各返信の「要約を表示」で確認できます。
- 設定メモ（system instruction）はどちらのモードでも毎回送られます。
- エラーで返信が得られなかった送信は、文脈には含まれません。同じ内容を再送しても、重複して送られることはありません。
- トークン数は文字数からの概算です。前回送信の実測値（`promptTokenCount`）も併記します。

## 設定項目

| 項目 | 内容 | 既定値 |
| --- | --- | --- |
| Gemini API キー | AI Studio で発行したキー | なし |
| 本文用モデル名 | 返信の生成に使うモデル（自由入力可） | `gemini-flash-latest` |
| 要約用モデル名 | 自動要約に使うモデル。軽量モデル向き | `gemini-flash-lite-latest` |
| テーマ | 端末に合わせる / ライト / ダーク | 端末に合わせる |
| 新規チャットの送信モード | 新しいチャットの初期モード | 要約＋直近 |
| 全文を送る話数 | 「要約＋直近」で全文を送る話数 | 2 |

## データの保存先

すべてブラウザの localStorage（オリジン単位）に保存されます。サーバーには何も送りません（Gemini API への通信を除く）。

| キー | 内容 |
| --- | --- |
| `gc_chats` | チャット履歴（設定メモ・要約・送信モードを含む） |
| `gc_cfg` | API キーと各種設定 |

別のブラウザや端末では履歴が見えません。移行にはバックアップ機能（全履歴のエクスポート / インポート）を使ってください。

## セキュリティ上の注意

- **API キーは平文で localStorage に保存されます。** 自分専用で使う前提の構成です。
- localStorage は **オリジン単位**で共有され、パスでは分かれません。`https://<user>.github.io/` 配下の別リポジトリのページからも、同じキーと履歴を読めてしまいます。気になる場合は、別アカウント・別ドメイン・Cloudflare Pages など別オリジンに置いてください。
- AI Studio で API キーに利用制限（HTTP リファラ、使える API の限定）をかけておくと、万一漏れても被害を抑えられます。
- 無料枠では、入力内容が Google の製品改善に使われる場合があります。機密情報を送る前に、最新の利用規約を確認してください。

## トラブルシューティング

| 症状 | 対処 |
| --- | --- |
| `HTTP 503: This model is currently experiencing high demand` | モデル側の混雑です。自動リトライ後も失敗する場合は「再試行」を押すか、本文用モデルを `gemini-flash-lite-latest` などに変えてみてください |
| `HTTP 400` / `HTTP 403` | API キーの誤り、またはキーの利用制限（リファラなど）に合致していない可能性があります |
| `HTTP 404` | モデル名のつづり違いの可能性があります。AI Studio のモデル一覧で確認してください |
| 更新したのに古い画面のまま | Service Worker のキャッシュが残っています。`Ctrl + Shift + R` で強制リロードしてください |
| ホーム画面に追加できない | HTTPS（または localhost）で開いているか確認してください |

## ファイル構成

```
gemini-chat-pwa/
├── index.html            アプリ本体（HTML / CSS / JavaScript が1ファイル）
├── manifest.webmanifest  PWA マニフェスト
├── sw.js                 Service Worker（ネットワーク優先、失敗時にキャッシュ）
├── icon-192.png          アイコン
├── icon-512.png          アイコン
└── README.md
```

外部ライブラリやビルド工程はありません。カスタマイズは `index.html` を直接編集してください。

## 使用している API

- `POST /v1beta/models/{model}:streamGenerateContent?alt=sse`（本文のストリーミング生成）
- `POST /v1beta/models/{model}:generateContent`（要約の生成）

認証は `x-goog-api-key` ヘッダーで行います。
